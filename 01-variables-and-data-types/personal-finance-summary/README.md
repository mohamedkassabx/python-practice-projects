# Personal Finance Summary

A simple Python project built while learning **Variables & Data Types**.

## About

This program collects a user's personal, income, and expense information, then calculates and displays a personal finance summary.

## Features

- Collects personal information
- Collects income details
- Collects expense details
- Calculates total income
- Calculates total expenses
- Calculates remaining balance
- Calculates spending percentage
- Displays a formatted financial summary

## Concepts Practiced

- Variables
- Data Types (`str`, `int`, `float`)
- User Input
- Type Casting
- Arithmetic Operations
- Formatted Output
- String Methods (`strip()`, `title()`)
- f-Strings

## Technologies

- Python
