# Text Formatter

A simple Python project built while learning Strings.

## About

This program collects text input from the user and displays different string formatting operations.

## Features

- Formats full name
- Formats email address
- Formats city name
- Formats a favorite quote
- Displays text length
- Displays first and last characters

## Concepts Practiced

- String Variables
- User Input
- String Methods (strip(), upper(), lower(), title(), capitalize())
- String Indexing
- len()
- Formatted Output
- f-Strings

## Technologies

- Python
