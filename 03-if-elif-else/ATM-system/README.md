# ATM System

A simple Python project built while learning If / Elif / Else.

## About

This program simulates a basic ATM system. It verifies the card number and PIN, then allows the user to withdraw money or check the account balance.

## Features

- Verifies card number and PIN
- Displays different login status messages
- Withdraws money from the account
- Checks available balance
- Prevents withdrawal when the balance is insufficient
- Displays a simple ATM menu

## Concepts Practiced

- Variables
- User Input
- Data Types (str, int, float)
- Conditional Statements (if, elif, else)
- Comparison Operators
- Arithmetic Operations
- Formatted Output
- f-Strings
