# Number Guessing Game

A simple Python project built while learning Loops (While Loop).

## About

This program challenges the user to guess a secret number. It keeps asking for guesses until the correct number is entered, then displays the total number of attempts.

## Features

- Repeatedly asks the user to guess a number
- Checks each guess against a secret number
- Counts the number of attempts
- Displays a special message for a correct first attempt
- Displays the total number of attempts after success

- Conditional Statements (if, else)

- User Input
