# Quiz Game

A simple Python project built while learning **Loops**.

## About

This program asks the user a series of quiz questions, checks each answer, and displays the final score with a performance summary.

## Features

- Asks multiple quiz questions
- Checks user answers
- Counts correct and wrong answers
- Calculates the final score
- Calculates the score percentage
- Displays a formatted summary

## Concepts Practiced

- Variables
- User Input
- Lists
- `for` Loops
- Conditional Statements (`if`, `else`)
- String Methods (`strip()`)
- `len()`
- Arithmetic Operations
- Formatted Output
- f-Strings
