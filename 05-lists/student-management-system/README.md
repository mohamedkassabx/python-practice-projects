# Student Management System

A simple Python project built while learning **Lists**.

## About

This program is a simple student management system that allows users to add, view, remove, and search for students using lists.

## Features

- Add new students
- View all students information
- Remove students
- Search for students by name
- Stores student names, ages, and grades
- Handles invalid inputs

## Concepts Practiced

- Lists
- Multiple Lists Management
- List Methods (`append()`, `pop()`, `index()`)
- `while` Loop
- `for` Loop
- `enumerate()`
- Membership Operator (`in`)
- Conditional Statements (`if`, `elif`, `else`)
- Exception Handling (`try`, `except`)
- User Input
- Formatted Output
- f-Strings
