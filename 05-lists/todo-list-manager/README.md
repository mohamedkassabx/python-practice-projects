# To-Do List Manager

A simple Python project built while learning **Lists and Loops**.

## About

This program is a simple task management system that allows users to add, view, remove, and manage tasks through a menu-based interface.

## Features

- Add new tasks
- View all tasks
- Remove tasks
- Interactive menu system
- Handles invalid menu inputs
- Displays formatted task lists

## Concepts Practiced

- Lists
- List Methods (`append()`, `pop()`)
- `while` Loop
- `for` Loop
- `enumerate()`
- Conditional Statements (`if`, `elif`, `else`)
- Exception Handling (`try`, `except`)
- User Input
- Formatted Output
- f-Strings

## Technologies

- Python
