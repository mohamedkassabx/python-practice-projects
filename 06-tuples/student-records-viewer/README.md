# Student Records Viewer

A simple Python project built while learning **Tuples**.

## About

This program displays student records stored in tuples. Users can view all students, search for a student by name, and display the total number of students.

## Features

- View all student records
- Search for a student by name
- Display the total number of students
- Uses immutable tuple data
- Handles invalid menu inputs

## Concepts Practiced

- Tuples
- Nested Tuples
- Tuple Unpacking
- `enumerate()`
- `len()`
- `for` Loop
- `while` Loop
- Conditional Statements (`if`, `elif`, `else`)
- Exception Handling (`try`, `except`)
- User Input
- f-Strings
- Boolean Flag
