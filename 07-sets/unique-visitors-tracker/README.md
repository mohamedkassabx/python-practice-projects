# Unique Visitors Tracker

A simple Python project built while learning **Sets**.

## About

This program manages a list of unique visitors. Users can add visitors, view all visitors, search for a visitor, remove visitors, and display the total number of visitors through a menu-driven interface.

## Features

- Add unique visitors
- Prevent duplicate visitor names
- View all visitors in alphabetical order
- Search for a visitor
- Remove a visitor
- Display the total number of visitors
- Handle invalid menu input

## Concepts Practiced

- Sets
- `add()`
- `discard()`
- `sorted()`
- `enumerate()`
- `len()`
- Membership Operator (`in`)
- `while` Loop
- Conditional Statements (`if`, `elif`, `else`)
- Exception Handling (`try`, `except`)
- User Input
- String Methods (`strip()`, `title()`)
