# Inventory Management System

A simple Python project built while learning **Dictionaries**.

## About

This program manages a simple product inventory system. Users can add products, view inventory, update product quantities, search for products, remove products, and display the total number of products through a menu-driven interface.

## Features

- Add new products
- Prevent duplicate products
- Update product quantities
- View all inventory items
- Search for products
- Remove products
- Display total number of products
- Validate product quantities
- Handle invalid menu input

## Concepts Practiced

- Dictionaries
- Dictionary Keys & Values
- `items()`
- `pop()`
- `len()`
- `for` Loop
- `while` Loop
- Conditional Statements (`if`, `elif`, `else`)
- Exception Handling (`try`, `except`)
- Type Conversion
- User Input
- String Methods (`strip()`, `title()`)
