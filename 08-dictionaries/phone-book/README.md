# Phone Book

A simple Python project built while learning **Dictionaries**.

## About

This program manages a simple phone book. Users can add contacts, view all contacts, search for a contact, remove contacts, and display the total number of saved contacts through a menu-driven interface.

## Features

- Add new contacts
- Prevent duplicate contact names
- Prevent duplicate phone numbers
- View all saved contacts
- Search for a contact by name
- Remove a contact
- Display the total number of contacts
- Handle invalid menu input

## Concepts Practiced

- Dictionaries
- Dictionary Keys & Values
- `pop()`
- `keys()`
- `values()`
- `len()`
- `for` Loop
- `while` Loop
- Conditional Statements (`if`, `elif`, `else`)
- Exception Handling (`try`, `except`)
- User Input
- String Methods (`strip()`, `title()`)
