# Employee Salary Calculator

A simple Python project built while learning **Functions**.

## About

This program calculates an employee's net salary based on the basic salary, bonus, and tax percentage. The program is divided into multiple functions, where each function handles a specific responsibility such as collecting data, calculating values, and displaying the final report.

## Features

- Enter employee information
- Calculate tax amount
- Calculate net salary
- Display a formatted employee report
- Validate tax percentage range
- Handle invalid numeric input
- Format salary values to two decimal places
