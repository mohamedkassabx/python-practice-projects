# Student Profile Card

A simple Python project built while learning **Variables & Data Types**.

## About

This program collects a student's personal and academic information from the user and displays it in a well-formatted profile card.

## Features

- Collects personal information
- Collects academic information
- Uses different Python data types
- Displays a formatted profile card

## Concepts Practiced

- Variables
- Data Types (`str`, `int`, `float`)
- User Input
- Type Casting
- Formatted Output
- String Methods (`strip()`, `capitalize()`)
- f-Strings

## Technologies

- Python
