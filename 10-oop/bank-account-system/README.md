# Bank Account System

A simple Python project built while learning **Object-Oriented Programming (OOP)**.

## About

This program simulates a simple bank account system using a Python class. It allows users to create a bank account, deposit money, withdraw money, check the current balance, and display account information.

## Features

- Create a bank account
- Deposit money
- Withdraw money
- Prevent invalid deposits
- Prevent withdrawals that exceed the available balance
- Display current balance
- Display account information
- Handle invalid numeric input
