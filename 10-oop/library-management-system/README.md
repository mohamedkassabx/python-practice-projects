# Library Management System

A simple Python project built while learning **Object-Oriented Programming (OOP)**.

## About

This program simulates a basic library management system. Users can add books, view all books, borrow books, return borrowed books, and check the total number of books in the library.

The project uses two classes: one to represent a book and another to manage the library.

## Features

- Add new books
- View all books
- Borrow a book
- Return a borrowed book
- Display each book's status (Available / Borrowed)
- Count total books
- Handle invalid numeric input
