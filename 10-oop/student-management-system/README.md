# Student Management System (OOP)

A simple Student Management System built with Python using Object-Oriented Programming (OOP).

## Features

- Add a new student
- View all students
- Search for a student by name
- Update a student's grade
- Remove a student
- Display the total number of students

## Concepts Practiced

- Classes and Objects
- Constructors (`__init__`)
- Instance Attributes
- Instance Methods
- Object Composition
- Lists of Objects
- User Input Validation
- Loops
- Conditional Statements
- Exception Handling (`try` / `except`)

## Project Structure

- `Student` class
  - Store student information
  - Display student details
  - Update student grade

- `StudentManager` class
  - Add students
  - View students
  - Search students
  - Update grades
  - Remove students
  - Count students
