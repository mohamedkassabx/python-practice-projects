# Student Records File Manager

A simple Python application for managing student records using a text file for data storage.

## Features

- Add a new student
- View all students
- Search for a student by name
- Count total students
- Store records permanently in a text file

## Data Format

Each student is stored as a single line in `students.txt`.

Example:

```text
Ali,20,95
Sara,21,88
Mohamed,22,100
```

## Concepts Practiced

- File Handling
- Reading Files
- Writing Files
- Append Mode
- String Splitting
- User Input Validation
- Loops
- Conditional Statements
- Exception Handling (`try` / `except`)

## Project Structure

- `main.py` — Main application
- `students.txt` — Student records
