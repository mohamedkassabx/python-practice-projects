# Username Generator

A simple Python project built while learning Strings.

## About

This program generates multiple username suggestions based on the user's personal information and displays basic string information about the user's full name.

## Features

- Generates multiple username suggestions
- Combines different string values
- Uses string slicing and indexing
- Displays name formatting
- Displays name length
- Displays first and last characters

## Concepts Practiced

- String Variables
- User Input
- String Concatenation
- String Slicing
- String Indexing
- Type Casting (str())
- len()
- String Methods (upper(), lower(), capitalize())
- Formatted Output
- f-Strings
