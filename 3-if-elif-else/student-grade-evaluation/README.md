# Student Grade Evaluation

A simple Python project built while learning If / Elif / Else.

## About

This program collects a student's academic information and evaluates their academic grade, attendance status, and project performance based on user input.

## Features

- Collects student information
- Evaluates academic grade
- Evaluates attendance status
- Evaluates project performance
- Displays a formatted evaluation report

## Concepts Practiced

- Variables
- User Input
- Data Types (str, int, float)
- Conditional Statements (if, elif, else)
- Comparison Operators
- Formatted Output
- f-Strings

## Technologies

- Python
