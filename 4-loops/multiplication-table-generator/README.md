# Multiplication Table Generator

A simple Python project built while learning Loops.

## About

This program generates a multiplication table for a given number within a user-defined range and displays a summary of the generated results.

## Features

- Generates a multiplication table
- Supports custom start and end multipliers
- Counts total multiplication operations
- Calculates the sum of all results
- Finds the largest result
- Finds the smallest result
- Validates the multiplication range
