# Shopping Cart System

A simple Python project built while learning **Lists**.

## About

This program simulates a simple shopping cart system where users can add products, view the cart, remove products, and check the total number of items.

## Features

- Add products to the cart
- View all products
- Remove products by number
- Count total items in the cart
- Handles invalid menu inputs
- Prevents empty product names

## Concepts Practiced

- Lists
- List Methods (`append()`, `pop()`)
- `while` Loop
- `for` Loop
- `enumerate()`
- Conditional Statements (`if`, `elif`, `else`)
- Exception Handling (`try`, `except`)
- User Input
- `len()`
- Formatted Output
- f-Strings
