# Student Grade Calculator

A simple Python project built while learning **Functions**.

## About

This program calculates a student's average grade and academic letter grade. The program is divided into multiple functions, each responsible for a specific task such as collecting input, calculating the average, determining the final grade, and displaying the report.

## Features

- Enter student information
- Validate empty inputs
- Validate grade values (0–100)
- Calculate the average grade
- Determine the final letter grade
- Display a formatted student report
- Handle invalid numeric input using exception handling
