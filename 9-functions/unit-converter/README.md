# Unit Converter

A simple Python project built while learning **Functions**.

## About

This program converts values between different temperature and distance units using separate functions. Each conversion is handled by its own function, while the main function manages the user interface and program flow.

## Features

- Convert Celsius to Fahrenheit
- Convert Fahrenheit to Celsius
- Convert Kilometers to Miles
- Convert Miles to Kilometers
- Display formatted conversion results
- Handle invalid numeric input
- Menu-driven interface
