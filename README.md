# Python Practice Projects

A collection of Python projects built throughout my Python learning journey.

This repository documents my progress from the very basics of Python to Object-Oriented Programming (OOP). Every project was created as hands-on practice to strengthen my understanding of programming concepts through real applications rather than only studying theory.

## About

The projects in this repository are organized by topic. Each folder focuses on a specific Python concept and contains one or more mini projects that apply what I learned.

The goal of this repository is to document my learning process, improve my problem-solving skills, and build a solid programming foundation before moving on to AI Engineering.

## Topics Covered

* Variables & Data Types
* Strings
* Conditional Statements
* Loops
* Lists
* Tuples
* Sets
* Dictionaries
* Functions
* File Handling
* Object-Oriented Programming (OOP)

## Skills Practiced

* Writing clean and organized Python code
* Input validation
* Error handling with `try` / `except`
* Working with files
* Creating reusable functions
* Using Python built-in data structures
* Object-Oriented Programming
* Menu-driven console applications
* Problem solving
* Code organization

## Repository Structure

Each topic has its own folder.

Inside every topic folder, each project has its own directory containing:

* `main.py`
* `README.md`

This makes every project independent and easy to navigate.
